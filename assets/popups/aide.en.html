Before you start: programs to install

NeuraDesk works on its own. The programs below are optional: each one unlocks an applet, which stays hidden or inactive without it.

  • NAPS2 — the Scanner applet, and the "built-in" text recognition.
    naps2.com/download — or winget install Cyanfrog.NAPS2
  • Everything — the File Search applet, which only appears with it.
    voidtools.com/downloads — or winget install voidtools.Everything
  • Voicemeeter — the Voicemeeter panel.
    vb-audio.com/Voicemeeter
  • VLC — "Show" on a video, in the folder dash (see "Playing videos" below).
    videolan.org — or winget install VideoLAN.VLC
  • PowerShell 7 — the "PowerShell 7" option in the Terminal (PowerShell 5 and the Command Prompt work without installing anything).
    winget install Microsoft.PowerShell
  • PawnIO — CPU temperature and power, in the System Monitor (see "CPU temperature" below).
    pawnio.eu — or winget install namazso.PawnIO
Your language for NAPS2 OCR — open NAPS2, then OCR, and choose your language (e.g. English): NAPS2 then downloads it. Without it, the built-in recognition refuses to start, and says so. The other engine, the Windows one, needs your language installed with its optical character recognition (Settings → Time & language → Language & region).

Playing videos: install VLC

In the folder dash, Show on a video plays it in a NeuraDesk window — play/pause, progress, volume, full screen. VLC does the playback: without it, a video's menu offers View help instead.

  • Download VLC from videolan.org — the Windows 64-bit version — and run the installer, keeping the default choices;
  • or, in a terminal: winget install VideoLAN.VLC.
After installing — reopen the folder in the dash: Show is back in the video menu, without restarting NeuraDesk. VLC must be installed in its usual location (C:\Program Files\VideoLAN\VLC); a 32-bit version won't work.

CPU temperature: install PawnIO

The System Monitor shows the CPU frequency without installing anything. Its temperature and power, however, are only exposed by Windows to a driver: NeuraDesk uses PawnIO, the signed driver also used by LibreHardwareMonitor and Fan Control.

  • In the System Monitor, Install PawnIO starts the installation (a terminal window, then an administrator prompt);
  • or download it from pawnio.eu;
  • or, in a terminal: winget install namazso.PawnIO.
Then, one administrator prompt per session — PawnIO only answers an administrator program, and NeuraDesk never is one. The first time you open the System Monitor, Windows therefore asks you to allow neuradesk-capteurs.exe: this small program reads the temperature and power every second, and stops with NeuraDesk. Nothing stays installed. If you decline, you won't be asked again until the next launch; the Show temperature button asks again. If the PawnIO installation asks you to restart, the temperature only appears afterwards.
The values — the temperature is the one the CPU reports to its controller (Tctl on AMD, the package temperature on Intel); the power is that of the whole package, from its energy counter. To remove PawnIO: Settings → Apps → Installed apps.

Fonts

Each style (Settings → Style) has its own font. If it is missing, Windows replaces it with Segoe UI: nothing breaks, but the style loses its look.

  • Noto Sans — KDE, deepin.
    fonts.google.com/noto/specimen/Noto+Sans
  • Adwaita Sans — GNOME.
    gitlab.gnome.org/GNOME/adwaita-fonts (Releases)
  • Inter — elementary.
    rsms.me/inter
  • Ubuntu — Cinnamon.
    fonts.google.com/specimen/Ubuntu
  • Open Sans — COSMIC.
    fonts.google.com/specimen/Open+Sans
  • Roboto — Android.
    fonts.google.com/specimen/Roboto
  • Segoe UI, Segoe UI Variable, Segoe Fluent Icons, Cambria Math — included with Windows 11, nothing to do.
Installing a font — extract the archive, select the .ttf or .otf files, right-click → Install for all users, then reopen Settings: the font list is reloaded every time it opens.

Terminal fonts

The terminals need nothing installed. NeuraDesk ships its own terminal font — Nordwand Mono, open-source license — inside the program: four declared weights, loaded on demand by the two pages that draw terminal text: the Terminal and SSH Servers.

  • Nordwand Mono — the one used by the terminals here, if you want it in Windows Terminal or VS Code too.
    github.com/tywr/Nordwand-Mono (Releases)
  • JetBrains Mono — the most complete of the free fonts: boxes, blocks and prompt glyphs.
    fonts.google.com/specimen/JetBrains+Mono
  • Cascadia Code — the Windows Terminal font; "Code" has the prompt glyphs, "Mono" doesn't.
    github.com/microsoft/cascadia-code (Releases)
  • Hack — the only one in this list that winget knows.
    winget install SourceFoundry.HackFonts
  • DejaVu Sans Mono — near-complete coverage, solid design; it's the one that lends Nordwand what it doesn't draw.
    dejavu.org
  • Fira Mono, Source Code Pro, Roboto Mono — open-source licenses, similar coverage.
    fonts.google.com
  • Consolas and Courier New — included with Windows, nothing to do.
Coverage before looks — a terminal font must draw boxes (┏━┛), blocks (█▓▒░) and arrows (▲▼). Nordwand Mono doesn't cover them: when a full-screen program (htop, lazygit, tmux) or a Powerline prompt outputs them, the page borrows them from the next font in its stack — measured: 18% wider than the cell, so the grid stays straight but the stroke changes weight and height. For prompt icons, install a Nerd Font: the same free fonts, patched with the icons.
github.com/ryanoasis/nerd-fonts (Releases)
It's adjustable — Settings → Style has "Terminal font": the list of fonts installed on this PC, each written in its own font, a filter field, and a button that restores the default stack. The chosen font is placed in front of the stack — Nordwand Mono → DejaVu Sans Mono → Cascadia Mono → Consolas → monospace — never in its place: the boxes and blocks of a font that doesn't draw them are still borrowed from the rest. The setting governs both surfaces, and tabs already open follow it without restarting the shell or reconnecting an SSH session.
Download, then install: a font only enters the list once Windows has registered it (see "Installing a font" above). A font that is set but missing from the PC is no danger — the terminal moves on to the next one in the stack, and Settings says so.
The bar and panel font is the other setting in the same section: "Font" replaces the style's font across the whole interface — never in the terminals.

The four bars

NeuraDesk replaces the taskbar with four bars: top, bottom, left and right. Each one's thickness is set independently in Settings, and each can be hidden.

  • Top — the clock, the reminder bell, the note icon, and the row of widgets.
  • Bottom — pinned folders and applications.
  • Left and right — the applets: power, sound, network, Voicemeeter, notes, theme, and the others.

Applets: one gesture, two doors

  • Left-click — opens the applet's panel, or runs its action (shut down, lock, toggle the theme…).
  • Right-click — opens a menu: that's where the applet's fine settings and shortcuts live.
  • Hover — the icon grows and shows its name.
Panels and menus look different for a reason: a menu anchors below its icon and closes as soon as you click elsewhere; a panel fills the free area between the bars and stays open until you close it.

Zones

The icons in the right bar are arranged in zones — named groups, separated by lines. A zone moves as a block, can be renamed, and an icon belongs to its zone: moving the zone moves everything it contains.

Menus

A menu opens below its icon, never over a bar: if there isn't enough room, it moves up or shifts sideways rather than covering the interface.

If a menu is too big for the screen, it shrinks just enough to fit — rather than being cut off. It's the same principle throughout the app: you never lose content.

The Dash

The Dash is the application grid. It is organized in categories, and an application can go in whichever category you like.

  • Pin — drag an icon onto the Dash, or use its menu.
  • Unpin — from the icon's menu.

Settings

Almost everything is adjusted from the Settings panel, and much of it per screen: each secondary screen has its own tab, where you set the size of menus, the Dash, the clipboard and each panel.

DPI ratio — the app adapts the perceived size to each screen's density, so a menu takes up the same space in your field of view everywhere. This ratio is calculated automatically, but each screen can override it, and a global setting overrides it on all screens at once — handy for checking the effect without changing resolution.

Full screen in the central area

With the Place full-screen applications in the central area setting, a game or video that goes full screen is placed between the bars. An application that immediately takes over the whole screen again is left in full screen, and the bars hide.

This is the case with browsers: in full-screen video (Twitch, YouTube…), they snap to the whole screen and refuse to be moved. Two solutions:

  • The site's theater mode — on Twitch, Alt+T: the video fills the browser window, which stays in the area.
  • The Windowed extension — sites' full-screen button fills the window instead of the screen.
    Chrome, Edge, Brave, Opera, Vivaldi:
    chromewebstore.google.com/detail/gibipneadnbflmkebnmcbgjdkngkbklb
    Firefox, LibreWolf, Waterfox, Zen:
    addons.mozilla.org/firefox/addon/windowed/

Gestures

  • Drag an icon — moves it within its bar, or from one zone to another. An elastic spacer absorbs the remaining space.
  • Right-click an empty space — offers to place a zone or a separator there, or to add an application.
  • Right-click a separator — sets its size, columns and lock.
  • Right-click a notification area icon — opens the application's real menu, the Windows one.
