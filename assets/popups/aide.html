Avant de commencer : les programmes à installer

NeuraDesk fonctionne seul. Les programmes ci-dessous sont facultatifs : chacun débloque une applet, qui reste absente ou inactive sans lui.

  • NAPS2 — l'applet Scanner, et la reconnaissance de caractères « intégrée ».
    naps2.com/download — ou winget install Cyanfrog.NAPS2
  • Everything — l'applet Recherche de fichiers, qui n'apparaît qu'avec lui.
    voidtools.com/downloads — ou winget install voidtools.Everything
  • Voicemeeter — le panneau Voicemeeter.
    vb-audio.com/Voicemeeter
  • VLC — « Afficher » sur une vidéo, dans le dash dossier (voir « Lire les vidéos » plus bas).
    videolan.org — ou winget install VideoLAN.VLC
  • PowerShell 7 — le choix « PowerShell 7 » du Terminal (PowerShell 5 et l'invite de commandes marchent sans rien installer).
    winget install Microsoft.PowerShell
Le français pour l'OCR de NAPS2 — ouvrir NAPS2, puis OCR, et choisir Français : NAPS2 télécharge alors la langue. Sans elle, la reconnaissance intégrée refuse de démarrer, et le dit. L'autre moteur, celui de Windows, demande la langue française avec sa reconnaissance optique de caractères (Paramètres → Heure et langue → Langue et région).

Lire les vidéos : installer VLC

Dans le dash dossier, Afficher sur une vidéo la lit dans une fenêtre de NeuraDesk — lecture/pause, progression, volume, plein écran. C'est VLC qui la lit : sans lui, le menu d'une vidéo propose Voir l'aide à la place.

  • Télécharger VLC sur videolan.org — la version Windows 64 bits — et lancer l'installation en gardant les choix proposés ;
  • ou, dans un terminal : winget install VideoLAN.VLC.
Après l'installation — rouvrir le dossier dans le dash : Afficher revient dans le menu des vidéos, sans relancer NeuraDesk. VLC doit être installé à son emplacement habituel (C:\Program Files\VideoLAN\VLC) ; une version 32 bits ne convient pas.

Les polices de caractères

Chaque style (Réglages → Style) a sa police. Si elle manque, Windows la remplace par Segoe UI : rien ne casse, mais le style perd son allure.

  • Noto Sans — KDE, deepin.
    fonts.google.com/noto/specimen/Noto+Sans
  • Adwaita Sans — GNOME.
    gitlab.gnome.org/GNOME/adwaita-fonts (Releases)
  • Inter — elementary.
    rsms.me/inter
  • Ubuntu — Cinnamon.
    fonts.google.com/specimen/Ubuntu
  • Open Sans — COSMIC.
    fonts.google.com/specimen/Open+Sans
  • Roboto — Android.
    fonts.google.com/specimen/Roboto
  • Segoe UI, Segoe UI Variable, Segoe Fluent Icons, Cambria Math — fournies avec Windows 11, rien à faire.
Installer une police — extraire l'archive, sélectionner les fichiers .ttf ou .otf, clic droit → Installer pour tous les utilisateurs, puis rouvrir les Réglages : la liste des polices est relue à chaque ouverture.

Les polices des terminaux

Les terminaux n'attendent rien à installer. NeuraDesk embarque sa propre police de terminal — Nordwand Mono, licence libre — dans le programme : quatre graisses déclarées, chargées à la demande par les deux pages qui peignent du texte en terminal : le Terminal et les Serveurs SSH.

  • Nordwand Mono — celle des terminaux ici, si on la veut aussi dans Windows Terminal ou VS Code.
    github.com/tywr/Nordwand-Mono (Releases)
  • JetBrains Mono — la plus complète des polices libres : boîtes, blocs et glyphes de prompt.
    fonts.google.com/specimen/JetBrains+Mono
  • Cascadia Code — la police de Windows Terminal ; « Code » porte les glyphes de prompt, « Mono » non.
    github.com/microsoft/cascadia-code (Releases)
  • Hack — la seule de cette liste que winget connaît.
    winget install SourceFoundry.HackFonts
  • DejaVu Sans Mono — couverture quasi totale, dessin solide ; c'est elle qui prête à Nordwand ce qu'elle ne dessine pas.
    dejavu.org
  • Fira Mono, Source Code Pro, Roboto Mono — licences libres, couvertures équivalentes.
    fonts.google.com
  • Consolas et Courier New — fournies avec Windows, rien à faire.
La couverture avant le dessin — une police de terminal doit dessiner les boîtes (┏━┛), les blocs (█▓▒░) et les flèches (▲▼). Nordwand Mono ne les couvre pas : quand un programme en plein écran (htop, lazygit, tmux) ou un prompt Powerline en émet, la page les emprunte à la police suivante de sa pile — mesuré : 18 % plus large que la cellule, donc la grille reste droite mais le trait change de graisse et de hauteur. Pour les icônes de prompt, installer une Nerd Font : les mêmes polices libres, patchées avec les icônes.
github.com/ryanoasis/nerd-fonts (Releases)
Ça se règle — Réglages → Style porte « Police des terminaux » : la liste des polices installées sur ce PC, chacune écrite dans sa police, un champ pour filtrer, et un bouton qui remet la pile par défaut. La police réglée est placée devant la pile — Nordwand Mono → DejaVu Sans Mono → Cascadia Mono → Consolas → monospace — jamais à sa place : les boîtes et les blocs d'une police qui ne les dessine pas restent empruntés à la suite. Le réglage gouverne les deux surfaces, et les onglets déjà ouverts le suivent sans relancer le shell ni reconnecter une session SSH.
Télécharger, puis installer : une police n'entre dans la liste que si Windows l'a enregistrée (voir « Installer une police » ci-dessus). Une police réglée mais absente du PC n'est pas un danger — le terminal passe à la suivante de la pile, et Réglages le dit.
La police des barres et des panneaux est l'autre réglage de la même section : « Police » remplace celle du style dans toute l'interface — jamais dans les terminaux.

Les quatre barres

NeuraDesk remplace la barre des tâches par quatre barres : haut, bas, gauche et droite. Chacune se règle indépendamment en épaisseur depuis les Réglages, et peut être masquée.

  • En haut — l'horloge, la cloche des rappels, l'icône de note, et la rangée de widgets.
  • En bas — les dossiers épinglés et les applications.
  • À gauche et à droite — les applets : alimentation, son, réseau, Voicemeeter, notes, thème, et les autres.

Les applets : un geste, deux portes

  • Clic gauche — ouvre le panneau de l'applet, ou lance son action (éteindre, verrouiller, basculer le thème…).
  • Clic droit — ouvre un menu : c'est là que vivent les réglages fins de l'applet et ses raccourcis.
  • Survol — l'icône grossit et affiche son nom.
Un panneau et un menu ne se ressemblent pas par hasard : un menu s'ancre sous son icône et se referme dès qu'on clique ailleurs ; un panneau occupe la zone libre entre les barres et reste ouvert tant qu'on ne le referme pas.

Les zones

Les icônes de la barre de droite sont rangées en zones — des groupes nommés, séparés par des traits. Une zone se déplace en bloc, se renomme, et une icône appartient à sa zone : la déplacer dans la zone déplace tout ce qu'elle contient.

Les menus

Un menu s'ouvre sous son icône, jamais par-dessus une barre : s'il n'y a pas la place, il remonte ou se décale plutôt que de recouvrir l'interface.

Si un menu est trop grand pour l'écran, il se réduit juste assez pour tenir — plutôt que d'être rogné. C'est le même principe partout dans l'application : on ne perd jamais de contenu.

Le Dash

Le Dash est la grille d'applications. Il se range en catégories, et une application se place dans la catégorie qu'on veut.

  • Épingler — glisser une icône sur le Dash, ou passer par son menu.
  • Désépingler — par le menu de l'icône.

Les Réglages

Presque tout se règle depuis le panneau des Réglages, et une grande partie par écran : chaque écran secondaire a son propre onglet, où l'on règle la taille des menus, du Dash, du presse-papiers et de chaque panneau.

Ratio de DPI — l'application adapte la taille perçue à la densité de chaque écran, pour qu'un menu occupe la même place dans le champ de vision partout. Ce ratio est calculé automatiquement, mais chaque écran peut le forcer, et un réglage global permet de le forcer sur tous les écrans à la fois — utile pour vérifier l'effet sans changer de résolution.

Le plein écran dans la zone centrale

Avec le réglage Placer les applications plein écran dans la zone centrale, un jeu ou une vidéo qui passe en plein écran est placé entre les barres. Une application qui reprend aussitôt tout l'écran est laissée en plein écran, et les barres se masquent.

C'est le cas des navigateurs : en plein écran vidéo (Twitch, YouTube…), ils s'alignent sur l'écran entier et refusent d'être déplacés. Deux solutions :

  • Le mode cinéma du site — sur Twitch, Alt+T : la vidéo remplit la fenêtre du navigateur, qui reste dans la zone.
  • L'extension Windowed — le bouton plein écran des sites remplit la fenêtre au lieu de l'écran.
    Chrome, Edge, Brave, Opera, Vivaldi :
    chromewebstore.google.com/detail/gibipneadnbflmkebnmcbgjdkngkbklb
    Firefox, LibreWolf, Waterfox, Zen :
    addons.mozilla.org/firefox/addon/windowed/

Les gestes

  • Glisser une icône — la déplace dans sa barre, ou d'une zone à l'autre. Un espace élastique absorbe la place restante.
  • Clic droit sur un espace vide — propose d'y poser une zone, un séparateur, ou d'y ajouter une application.
  • Clic droit sur un séparateur — règle sa taille, ses colonnes et son verrouillage.
  • Clic droit sur une icône de la zone de notification — ouvre le vrai menu de l'application, celui de Windows.
