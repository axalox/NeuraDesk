NeuraDesk — logiciels et polices à installer

NeuraDesk fonctionne seul : son moteur d'affichage (CEF) et le runtime Visual C++ sont fournis avec lui. Tout le reste est facultatif, chaque programme n'y débloquant qu'une applet précise, qui reste simplement absente ou inactive sans lui.

0. Runtime Microsoft Visual C++ 2015-2022 (x64) — fourni

Rien à installer. L'archive portable contient les trois fichiers du runtime dont NeuraDesk a besoin, à côté de neuradesk.exe : vcruntime140.dll, vcruntime140_1.dll et msvcp140.dll, copiés du redistribuable de Microsoft.

Si l'un de ces fichiers a été supprimé, NeuraDesk se lance puis s'arrête aussitôt, sans fenêtre et sans message. Il suffit alors de réextraire l'archive, ou d'installer le redistribuable de Microsoft ci-dessous.
En secoursComment le vérifierTéléchargement
Visual C++ Redistributable 2015-2022, x64 Le fichier C:\Windows\System32\msvcp140.dll existe. vc_redist.x64.exe
ou winget install Microsoft.VCRedist.2015+.x64

Le programme d'installation de Microsoft demande un redémarrage dans certains cas ; NeuraDesk fonctionne dès l'installation terminée, sans redémarrer.

Après l'installation de NAPS2 : la langue française de l'OCR

  1. Ouvrir NAPS2, puis OCR (icône de la barre d'outils).
  2. Choisir la langue Français : NAPS2 télécharge alors le paquet de langue dans %APPDATA%\NAPS2\components\tesseract4.
  3. Sans ce paquet, la reconnaissance « intégrée » de NeuraDesk refuse de démarrer et le dit.

La reconnaissance de caractères de Windows

Le second moteur d'OCR est celui de Windows. Il demande la langue française avec sa fonctionnalité « reconnaissance optique de caractères » : Paramètres → Heure et langue → Langue et région → Français → Options de langue. Elle est en général déjà présente sur un Windows en français.

2. Polices de caractères

Chaque style de NeuraDesk (Réglages → Style) a sa police. Si elle manque, Windows la remplace par Segoe UI : rien ne casse, mais le style perd son allure. La police se change aussi à la main dans Réglages.

Installer une police

  1. Télécharger l'archive (bouton « Get font » puis « Download all » sur Google Fonts).
  2. Extraire l'archive.
  3. Sélectionner les fichiers .ttf ou .otf, clic droit → Installer pour tous les utilisateurs.
  4. Rouvrir les Réglages de NeuraDesk : la liste des polices est relue à chaque ouverture.
Polices « variables » : une police à axes (Adwaita Sans, Inter, Roboto…) peut apparaître sous un nom un peu différent. Le style GNOME attend Adwaita Sans Text — c'est le nom sous lequel Windows range ses instances.
