# NeuraDesk — instructions pour Claude Code

## Documentation de référence

Le dossier `docs/` contient de la documentation externe (API, specs...) à
consulter avant toute tâche qui pourrait s'y rapporter — par exemple avant
d'intégrer ou de modifier du code touchant une bibliothèque/API qui y est
documentée. Vérifier son contenu (`ls docs/` ou équivalent) plutôt que de
supposer qu'il est vide ou sans rapport.
